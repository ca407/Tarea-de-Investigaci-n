01

Del terreno al chasis

El problema de ingeniería

La suspensión transmite fuerzas entre la rueda y el chasis. El objetivo es equilibrar confort, recorrido mecánico y contacto con el suelo. La suspensión activa añade una fuerza regulada por un actuador hidráulico o neumático.

En un robot móvil, la misma estructura permite estudiar la vibración vertical de una plataforma que transporta sensores o carga. Este modelo representa una esquina del vehículo; no incluye cabeceo, balanceo ni interacción entre ruedas.

El planteamiento de cuarto de vehículo se apoya en CTMS, Universidad de Michigan. La discusión de objetivos y limitaciones se apoya en MathWorks: Active Suspension.

Arquitectura del control

PlantaChasis, rueda, suspensión y neumático.
SensorTransductor de recorrido relativo y estimador filtrado de velocidad relativa.
ControladorRealimentación de velocidad: u = −g(vₛ − vᵤ).
ActuadorCilindro ideal que aplica +u al chasis y −u a la rueda.
PerturbaciónAltura del camino r(t); cambios de carga no modelados.
Aquí el actuador sintetiza amortiguamiento adicional. Es una estrategia sencilla de control activo, equivalente a aumentar un amortiguador ideal; no se afirma que sea un controlador óptimo ni que mejore todas las métricas.
02

Modelo físico, paso a paso

Definir el equilibrio

Desplazamientos verticales positivos hacia arriba, medidos desde el equilibrio estático. La gravedad queda compensada por la precarga. Se suponen pequeños recorridos, resortes lineales, fricción viscosa y contacto permanente del neumático.

Aplicar la segunda ley de Newton

El resorte depende del recorrido relativo y el amortiguador de la velocidad relativa. Las fuerzas de suspensión y del actuador cambian de signo entre las dos masas.

mₛz̈ₛ = −kₛ(zₛ − zᵤ) − c(vₛ − vᵤ) + u
mᵤz̈ᵤ = kₛ(zₛ − zᵤ) + c(vₛ − vᵤ) − kₜ(zᵤ − r) − u

Cerrar la realimentación

Con g ≥ 0, la fuerza se opone al movimiento relativo. Al sustituirla, el amortiguamiento efectivo es b.

u = −g(vₛ − vᵤ) = −Kx, K = [0 g 0 −g], b = c + g

¿Se necesita Taylor?
Las leyes adoptadas ya son lineales. No se inventa una linealización adicional: los términos no lineales reales, como saturación, fricción seca y dinámica de válvulas, quedan fuera de este modelo.
03

Del estado a la transferencia

Se elige x = [zₛ, vₛ, zᵤ, vᵤ]ᵀ, entrada de fuerza u, perturbación r y salida y = zₛ. Así, ẋ = Ax + Bᵤu + Bᵣr; y = Cx.

A = [0100−kₛmₛ−cmₛkₛmₛcmₛ0001kₛmᵤcmᵤ−(kₛ+kₜ)mᵤ−cmᵤ]
Bᵤ = [01mₛ0−1mᵤ] Bᵣ = [000kₜmᵤ]
C = [1 0 0 0], D = [0 0], Acl = A − BᵤK

Diagrama de integradores

Cada cadena integra aceleración → velocidad → posición. Las dos ecuaciones se acoplan mediante todos los estados relativos, con los signos de A. El camino r entra por Bᵣ y la fuerza u por Bᵤ.

G(s) = C(sI − A)⁻¹B + D, B = [Bᵤ Bᵣ]
Ver la eliminación algebraica en Laplace

Con condiciones iniciales nulas y u ya sustituida, las ecuaciones son:

(mₛs² + bs + kₛ)Zₛ − (bs + kₛ)Zᵤ = 0
−(bs + kₛ)Zₛ + (mᵤs² + bs + kₛ + kₜ)Zᵤ = kₜR

Se elimina Zᵤ multiplicando la primera ecuación por el coeficiente diagonal de la segunda. El determinante común es Δ, que se expande abajo.

Gᵣ(s;b) = Zₛ(s)R(s) = kₜ(bs + kₛ)Δ(s;b)
Δ = mₛmᵤs⁴ + b(mₛ+mᵤ)s³ + [kₛ(mₛ+mᵤ)+mₛkₜ]s² + bkₜs + kₛkₜ

Pasiva: b = c, u = 0. Activa: b = c + g. Ambas respuestas reciben exactamente el mismo escalón de carretera. No se trata de seguimiento de una referencia de posición.

Gᵤ(s) = Zₛ(s)U(s) = mᵤs² + kₜΔ(s;c) (R = 0)

Gᵤ representa la planta abierta desde fuerza a posición, con carretera fija. Gᵣ representa la transmisión de perturbaciones desde el camino al chasis; sus ceros son distintos.

Validación reproducible en GNU Octave

El script usa los valores nominales de la tabla, compara espacio de estados con funciones de transferencia y exporta dos gráficas. Cambia sus parámetros si deseas reproducir otra configuración del simulador.

suspension_activa.m
% ================================================================
% TEMA 3 | SUSPENSION ACTIVA AUTOMOTRIZ Y ROBOTICA MOVIL
% Modelo didactico de un cuarto de vehiculo. Unidades SI.
% Requiere el paquete control: instalar una sola vez si hace falta.
% ================================================================
clear; close all; clc;
pkg load control;

% ---- 01. PARAMETROS Y ENTRADA ------------------------------------
ms = 300; mu = 40;          % masas suspendida / no suspendida [kg]
ks = 16000; kt = 190000;    % rigidez suspension / neumatico [N/m]
c = 1000; g = 2000;        % amortiguamiento / ganancia [N*s/m]
h = 0.05;                 % desnivel permanente de carretera [m]
t = (0:0.001:5)';
r = h * ones(size(t));

% ---- 02. ESPACIO DE ESTADOS --------------------------------------
% x = [zs; vs; zu; vu], y = zs, u = fuerza sobre el chasis.
A = [0 1 0 0; -ks/ms -c/ms ks/ms c/ms; ...
     0 0 0 1; ks/mu c/mu -(ks+kt)/mu -c/mu];
Bu = [0; 1/ms; 0; -1/mu];
Br = [0; 0; 0; kt/mu];
Cy = [1 0 0 0];
K = [0 g 0 -g];           % u = -K*x = -g*(vs-vu)
Acl = A-Bu*K;
P = ss(A,Br,Cy,0);
T = ss(Acl,Br,Cy,0);

% ---- 03. TRANSFERENCIAS Y VERIFICACION ---------------------------
den = @(b) [ms*mu, b*(ms+mu), ...
  ks*(ms+mu)+ms*kt, b*kt, ks*kt];
Gp = tf([kt*c kt*ks],den(c));
Ga = tf([kt*(c+g) kt*ks],den(c+g));
disp('Polos pasivos:'); disp(eig(A));
disp('Polos activos:'); disp(eig(Acl));
disp('Ceros carretera -> chasis:'); disp(zero(Gp)); disp(zero(Ga));
disp('Valores finales [m]:'); disp(h*[dcgain(P),dcgain(T)]);
assert(all(real(eig(A))<0) && all(real(eig(Acl))<0));
assert(abs(dcgain(P)-1)<1e-8 && abs(dcgain(T)-1)<1e-8);

% ---- 04. RESPUESTAS Y METRICAS -----------------------------------
[yp,~,xp] = lsim(P,r,t);
[ya,~,xa] = lsim(T,r,t);
assert(max(abs(yp-lsim(Gp,r,t)))<1e-7);
assert(max(abs(ya-lsim(Ga,r,t)))<1e-7);
u = -xa*K';
ap = xp*A(2,:)'; aa = xa*Acl(2,:)';
fprintf('Pico aceleracion pasiva/activa [m/s^2]: %.4f / %.4f\n', ...
  max(abs(ap)), max(abs(aa)));
fprintf('Pico fuerza activa [N]: %.4f\n',max(abs(u)));
fprintf('Pico recorrido activo [m]: %.5f\n',max(abs(xa(:,1)-xa(:,3))));

% ---- 05. FIGURAS ORIGINALES PARA LA PRESENTACION ------------------
figure(1);
subplot(2,1,1); plot(t,1000*yp,'b',t,1000*ya,'r',t,1000*r,'k--');
grid on; ylabel('Chasis [mm]'); legend('Pasiva','Activa','Carretera');
title('Respuesta a un desnivel permanente de 5 cm');
subplot(2,1,2); plot(t,u,'r'); grid on;
xlabel('Tiempo [s]'); ylabel('Fuerza [N]');
print('suspension_respuesta.png','-dpng','-r150');
figure(2); plot(real(eig(A)),imag(eig(A)),'bx', ...
  real(eig(Acl)),imag(eig(Acl)),'ro');
grid on; xlabel('Parte real [1/s]'); ylabel('Parte imaginaria [rad/s]');
legend('Pasiva','Activa'); title('Polos del sistema');
print('suspension_polos.png','-dpng','-r150');
% Sin saturacion, retardo ni dinamica hidraulica del actuador.
% Un escalon es un desnivel permanente; no un bache de duracion finita.

05

Estabilidad y conclusiones

¿Por qué el sistema es estable?

Los polos son las raíces de Δ o los autovalores de A y Acl. Para masas y rigideces positivas y b > 0, la energía del sistema sin entrada de carretera cumple:

E = mₛvₛ² + mᵤvᵤ² + kₛ(zₛ−zᵤ)² + kₜzᵤ²2
Ė = −(c+g)(vₛ−vᵤ)² ≤ 0

La energía no aumenta. Además, mantener vₛ = vᵤ durante todo el movimiento obliga, por las ecuaciones de las dos masas y la rigidez del neumático, a reposo en el origen. El único conjunto invariante con Ė = 0 es el equilibrio: la estabilidad es asintótica. La suspensión pasiva ya es estable; el control modifica sus modos.

Ceros de las dos transferencias

s₀ = −kₛb ; ceros de Gᵤ: s = ±jkₜmᵤ

Nominalmente, el cero carretera→chasis pasa de −16 a −5,33 s⁻¹; los ceros fuerza→chasis son ±j68,92 rad/s. Los polos numéricos aparecen en el laboratorio y se calculan también en Octave.

Teorema del valor final

Para un escalón de altura h y polos en el semiplano izquierdo:

zₛ(∞) = lims → 0 sGᵣ(s;b)hs = h, u(∞) = 0

El chasis termina a la nueva altura del camino y la velocidad relativa se anula. El controlador modifica el transitorio; no mantiene indefinidamente el chasis en su altura absoluta anterior.

Lectura de ingeniería

  • El resorte almacena energía y el amortiguador la disipa.
  • La rueda y el chasis producen dos pares de modos, por eso se necesitan cuatro estados.
  • El confort debe evaluarse con aceleración, junto al recorrido y a la fuerza disponible.
  • En robótica, cada masa, rigidez y ganancia debe adaptarse al tamaño de la plataforma; estos valores no se transfieren directamente.
  • Una implementación real requiere sensores filtrados, límites del actuador y verificación del contacto del neumático.
